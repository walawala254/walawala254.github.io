What this test proves.

GSAP animates a five-property state object and Canvas redraws only while that state changes. A ResizeObserver keeps the drawing buffer aligned with its CSS size, with a capped pixel ratio to control work on high-density screens.

The semantic narrative and SVG fallback remain available when Canvas or JavaScript is unavailable.
