What this test proves.

The Three.js module is requested only when the prototype approaches the viewport. Rendering starts only while visible, pauses when the tab is hidden, and uses lower geometry detail, no antialiasing, and a 1.0 pixel ratio cap on narrow or low-power devices.

Context failure returns to the inline SVG. Teardown stops the animation loop, disconnects observers, disposes geometries, materials, any discovered textures, and the renderer, then releases the WebGL context.
