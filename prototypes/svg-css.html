What this test proves.

The SVG remains meaningful without JavaScript. GSAP addresses only transforms, visibility, fill, and stroke progression; ScrollTrigger starts the sequence in view, while gsap.matchMedia() replaces motion with the complete state when reduced motion is requested.

No scene, shader, model, texture, or continuous render loop is required.
